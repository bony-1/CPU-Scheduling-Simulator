CPU SCHEDULING • DOCUMENTATION

Learn. Understand. Simulate.

Everything you need to understand CPU Scheduling and its major algorithms.

01 • BASICS

What is CPU Scheduling?

CPU Scheduling is the process of deciding which process gets the CPU for execution. The CPU scheduler selects a process from the ready queue whenever the CPU becomes available.

02 • OBJECTIVES

Why CPU Scheduling?

Scheduling allows one process to use the CPU while another waits for I/O or other resources.

  • Maximum CPU utilization
  • Fair allocation of CPU
  • Maximum throughput
  • Minimum turnaround time
  • Minimum waiting time
  • Minimum response time
03 • TERMINOLOGY

Important Terminologies

  • Burst Time: Time required to complete execution.
  • Arrival Time: Time when a process enters the ready state.
  • Finish Time: Time when a process completes execution.
  • Multiprogramming: Multiple programs present in memory.
  • Process: A program currently in execution.
  • CPU/IO Burst Cycle: Alternating CPU and I/O activity.
04 • TYPES

Types of Scheduling

Preemptive

The OS can interrupt a running process and give the CPU to another process with higher priority.

Non-Preemptive

Once a process gets the CPU, it keeps it until it finishes or voluntarily releases the CPU.

05 • ALGORITHMS

CPU Scheduling Algorithms

FCFS

First Come First Serve — processes execute in arrival order.

SJF

Shortest Job First — the shortest process is selected first.

SRTF

Shortest Remaining Time First — a preemptive version of SJF.

Priority

Processes are selected according to their priority.

Round Robin

Each process gets an equal CPU time quantum in rotation.

Multilevel Queue

Processes are separated into different scheduling queues.
